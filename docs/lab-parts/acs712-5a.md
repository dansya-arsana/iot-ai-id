# ACS712-5A

Protocol: `adc` (analog output, ratiometric to the supply).

- Device (simulation): `apps/web/src/lab/sim/devices/acs712-5a.ts`
- Part (3D): `apps/web/src/lab/scene/parts/acs712-5a.ts`
- Test: `tests/lab-part-acs712-5a.test.ts`
- Pins: VCC, OUT, GND (breadboard columns 0, 1, 2), IP+ and IP- (screw terminals, wires only)

Behaviour: `VIOUT = VCC/2 + 0.185 V/A x (VCC/5) x I`, saturating 0.2 V from either rail, 4.5-5.5 V supply, about 10 mA. IP+ and IP- are one copper path, so the sensor can sit in series between a source and a load. The simulator has no current solver, so the current is a popover value (-5..+5 A). DC only: an AC sine would alias against the 1 ms simulation slice, so it is not offered. No noise is added (the real part has about 21 mV peak-to-peak).

Sketch tip: read OUT, subtract 512 counts for zero, then amps = (counts - 512) x 5 / 1023 / 0.185.

Provenance: own model and behaviour from the public Allegro datasheet facts (SOIC-8, 185 mV/A, VCC/2 offset, 31 x 13 mm module). No vendor model, logo or art.
