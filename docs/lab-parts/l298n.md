# L298N motor driver

Protocol: `pwm`.

- Device: `apps/web/src/lab/sim/devices/l298n.ts`
- Part: `apps/web/src/lab/scene/parts/l298n.ts`
- Test: `tests/lab-part-l298n.test.ts`
- Pins: ENA, IN1-IN4, ENB, GND

Model: per-bridge truth table, EN/IN PWM averaging, 2 V drop, VS input. Outputs exposed in state only (no part-to-part motor link).

Provenance: own work from public datasheet behaviour and typical module dimensions; no vendor models, photos or logos.
