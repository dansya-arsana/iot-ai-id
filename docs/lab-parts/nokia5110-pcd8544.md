# NOKIA5110-PCD8544

Protocol: `spi`. An 84 x 48 monochrome LCD with a PCD8544 controller on the common 8-pin breakout. The interface is write-only SPI, mode 0, MSB first, 4 Mbit/s maximum, with a DC pin that says command or data.

- Device (simulation): `apps/web/src/lab/sim/devices/nokia5110-pcd8544.ts`
- Part (3D): `apps/web/src/lab/scene/parts/nokia5110-pcd8544.ts`
- Test: `tests/lab-part-nokia5110-pcd8544.test.ts` (command and addressing tests plus the real sketch `tests/fixtures/sketches/pcd8544-hello.ino`)
- Pins, in module order: RST, CE, DC, DIN, CLK, VCC, LIGHT, GND (breadboard legs). Wire DIN to D11 and CLK to D13 (hardware SPI); CE, DC and RST are any digital pins. CE may go straight to GND.

## What is simulated

- Every byte comes from the AVR SPI master (`SPI.transfer`); DC at that moment picks command or data. SPI mode 1 and 2 bytes are dropped and counted (`badMode`), a LSB-first master gets its bytes bit-reversed, like the real chip would see them.
- Function set `0x20 | PD<<2 | V<<1 | H`: power down (RAM kept), vertical addressing, extended instruction set. Basic set (H=0): display control `0x08 | D<<2 | E` (blank, normal 0x0C, all on 0x09, inverse 0x0D), Y bank `0x40..0x45`, X column `0x80..0xD3`. Extended set (H=1): temperature coefficient `0x04..0x07`, bias `0x10..0x17`, Vop `0x80 | n`. NOP `0x00`. Out-of-range addresses and commands that do not belong to the current set count as `invalid`.
- DDRAM 84 x 6 bytes, one byte = vertical strip of 8 pixels, bit 0 on top. Horizontal addressing wraps column 83 into the next bank and bank 5 into bank 0; vertical addressing goes down the banks then to the next column.
- Reset: RST low (or power on) puts the chip in power-down with Vop 0, H=0, blank display; the RAM is not cleared. RAM is filled with deterministic noise at power up, so an uncleared screen shows snow. While RST is held low the interface ignores bytes. The first rise of RST counts as the end of a reset that began at power up (the pin sits low from the start).
- Contrast: Vlcd = 3.06 + 0.06 x Vop volts. Blank below about 5.8 V, good near 6.6 to 7.2 V, glass darkens past about 7.6 V (visual factors in the part). Bias and temperature coefficient are stored and shown in the state but do not change the picture.
- LIGHT: active low by default (pull to GND), popover switches to active high. It is read from the net voltage (`ctx.volts`), so a PWM pin dims it.

## Limits

- A sketch that bit-bangs the bus with `shiftOut` on other pins is not decoded: only hardware SPI (D11, D13) reaches the model.
- The part is rated 2.7 to 3.3 V on VCC. The logic pins are not level-checked: an Uno drives them at 5 V, which many tutorials do through resistors.
- The module is drawn with its header at the bottom edge to stand on the breadboard.

## Provenance

Own work from the public PCD8544 datasheet behaviour (instruction set, addressing, reset state, Vlcd formula). Dimensions (43 x 43 mm board, about 30 x 20 mm active area) are approximate for the generic red breakout; no vendor art, photos or logos.
