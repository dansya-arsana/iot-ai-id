# DS18B20

Protocol: `onewire` (real 1-Wire at signal level). Package choice in the popover: TO-92 chip or waterproof probe.

- Device (simulation): `apps/web/src/lab/sim/devices/ds18b20.ts`
- Part (3D): `apps/web/src/lab/scene/parts/ds18b20.ts` (`to92Body` is shared with `lm35.ts`)
- Tests: `tests/lab-part-ds18b20.test.ts`, fixture sketch `tests/fixtures/sketches/ds18b20-read.ino` (our own bit-banging master)
- Pins: GND, DQ, VDD (TO-92 order seen from the flat face; the probe cable is black, yellow, red in the same order)

## What is simulated

- Reset: low >= 400 us detected (datasheet master minimum 480 us); presence pulse 30 us after the release, 120 us long.
- Slots: a write is decided from the low time (< 30 us = 1, longer = 0); a read slot answers 0 by holding DQ low for 30 us from the falling edge.
- ROM: 0x28, serial derived from the part id, CRC8. Commands 0x33, 0x55, 0xCC, 0xF0 (SEARCH: bit, complement, direction), 0xEC (ALARM SEARCH).
- Function: 0x44 Convert T (93.75 / 187.5 / 375 / 750 ms by resolution, read slots return 0 while busy), 0xBE (9 bytes, last is CRC8), 0x4E (TH, TL, config), 0x48 (10 ms), 0xB8, 0xB4.
- Temperature word: signed 1/16 degC, 9/10/11 bit zeroes the low 3/2/1 bits. Power-on scratchpad is +85 degC (`50 05 4B 46 7F FF 0C 10 1C`).
- Several sensors on one wire form a wired-AND line (module-private bus per env and pin), so SEARCH ROM finds all of them.

## Simplifications

- The 4.7k pull-up that real wiring needs is assumed present (`ctx.line` idles the wire high); parasitic power only changes the READ POWER SUPPLY answer.
- No accuracy error (+-0.5 degC) and no strong-pullup timing; the thermometer value is exactly the popover value, quantised.
- The device keeps its own pull bookkeeping because `Env.setPin` is a single external level; a core "open-drain line with several drivers" helper would let this move out of the device (see report).

## Provenance

Own work from the public datasheet behaviour (timings, command set, CRC polynomial). The TO-92 and probe shapes are our own geometry from the package drawing dimensions; no vendor models, logos or images.
