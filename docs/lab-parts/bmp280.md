# BMP280

Protocol: `i2c`. Pressure and temperature (no humidity), 3.3 V breakout (rating 1.71 V to 3.6 V, so 5 V on VCC raises a power warning).

- Device: `apps/web/src/lab/sim/devices/bmp280.ts`; part: `apps/web/src/lab/scene/parts/bmp280.ts`; test: `tests/lab-part-bmp280.test.ts` (real firmware: Wire plus the Bosch 64-bit integer formulas, `tests/fixtures/sketches/bmp280-read.ino`)
- Pins: VCC, GND, SCL, SDA, CSB, SDO. Address 0x76 (SDO to GND or open), 0x77 (SDO to the supply). Chip id 0x58 at 0xD0.

Registers: reset 0xE0 (0xB6), status 0xF3 (measuring, im_update for 2 ms after power-on), ctrl_meas 0xF4, config 0xF5 (t_sb, filter), data 0xF7..0xFC, calibration 0x88..0x9F. Modes sleep, forced (back to sleep) and normal (t_standby 0.5 ms to 4 s). Conversion time 1.25 + 2.3*Tosr + 2.3*Posr + 0.575 ms; resolution 16 to 20 bit by oversampling; a read burst sees one consistent copy of the data registers. The popover values are turned into raw words by inverting the datasheet compensation (bisection), so the standard formulas read them back.

Assumption to verify against the datasheet: the IIR filter is applied to both pressure and temperature (the BME280 text says so; the BMP280 wording was not re-checked).

Provenance: own work from the public datasheet behaviour (register map, formulas); trim values are our own set; geometry is our own (sensor 2.0 x 2.5 x 0.95 mm).
