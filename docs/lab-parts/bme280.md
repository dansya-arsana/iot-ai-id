# BME280

Protocol: `i2c`. Bosch BME280 humidity, pressure and temperature sensor on a purple GY-BME280 style breakout (6 pins: VCC GND SCL SDA CSB SDO).

- Device (simulation): `apps/web/src/lab/sim/devices/bme280.ts`
- Part (3D): `apps/web/src/lab/scene/parts/bme280.ts`
- Test: `tests/lab-part-bme280.test.ts`

## Fidelity

- Address 0x76 (SDO to GND or open) or 0x77 (SDO wired to 5V).
- Register map: id 0xD0 = 0x60, reset 0xE0 (0xB6), ctrl_hum 0xF2, status 0xF3, ctrl_meas 0xF4, config 0xF5, data 0xF7..0xFE, calibration 0x88..0xA1 and 0xE1..0xE7. Auto-increment on burst read/write.
- Modes sleep, forced (measures, then returns to sleep, status bit 3 while converting) and normal. Oversampling sets the raw resolution (16..20 bit); 0 skips the channel (reads 0x80000 / 0x8000). ctrl_hum applies on the next ctrl_meas write.
- Popover temperature, humidity and pressure are converted to raw ADC words by inverting the datasheet integer compensation formulas (4.2.3) against a fixed calibration set, so Bosch-formula sketches read the values back.
- Not modelled: IIR filter, standby time in normal mode, SPI.

## Provenance

Own work from the public datasheet behaviour (BST-BME280-DS002). No vendor model, photo or logo. The calibration constants are a plausible trim set, not copied from a specific chip.
