# Lab parts

80 registered kinds. The live list is the registry: `registry.kinds()` in `scene/parts/index.ts`. Gallery: `/lab/parts` (all kinds) and `/lab/parts/<kind>` (one, large). New kinds are scaffolded with `npm run lab:new-part`.

66 kinds below have a page. The original built-in kinds (button, buzzer, diode, hcsr04, lamp, ldr, led, motor, obstacle, potentiometer, resistor, rgb-led, servo, transistor) are described in `docs/lab-extending.md` and in the lessons that use them.
