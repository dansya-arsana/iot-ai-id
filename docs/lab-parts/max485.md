# MAX485 RS-485 module

Status: emulated (transmit side only). Protocol: `uart`.

- Device: `apps/web/src/lab/sim/devices/max485.ts`; part: `apps/web/src/lab/scene/parts/max485.ts`; test: `tests/lab-part-max485.test.ts`
- Catalog record: `packages/catalog/data/max485.json`
- Pins (`MAX485_PINS`): logic header `RO, RE, DE, DI` (breadboard holes 0-3), bus header `VCC, B, A, GND` and screw terminals `A_T, B_T` (wires only, same nets as A and B).

## Behaviour

- Bytes the sketch sends on TX (DI) reach the bus only while DE is high. Bytes sent with DE low are counted as `driverOffBytes`.
- Bytes are grouped into Modbus RTU frames by a silence of 3.5 characters (11 bits each) at the `baud` prop (4800, 9600, 19200). The CRC-16 (poly 0xA001, init 0xFFFF, low byte first) is checked. State holds the last frame: address, function, start register, count, `crcOk`.
- No bus partner is emulated: the platform has no device-to-device byte link (`ctx.peers` gives pins, not models), so the probe behind A/B cannot answer from its own state. A reply exists only if you paste hex in the popover terminal; it goes out on RO with 10-bit timing, and only while RE is low.
- Core gap to report: an RS-485 / byte-link helper in `sim/devices/core`, so `max485` and `soil-npk-rs485` can talk.

## Provenance

- MAX1487-MAX491 datasheet (K): https://www.analog.com/media/en/technical-documentation/data-sheets/MAX1487-MAX491.pdf : 4.75-5.25 V, half-duplex, 2.5 Mbit/s, 32 unit loads, DE active high, RE active low.
- Module size (U): https://protosupplies.com/product/max485-ttl-to-rs-485-interface-module/ , https://makerselectronics.com/ar/product/max485-ttl-to-rs485-converter-module/

## Sources disagree

- Size: vendors list 44 x 13 to 45 x 20 mm. We model 44 x 14 x 12 mm.
- Terminator: 120 ohm on most modules, some 100 ohm. We mark 120 ohm.
- The brief says bytes reach the bus while "DE=1 and RE=1". The datasheet enables the driver with DE alone, so we use DE only; RE only decides whether RO is live.

## Design checks for Pro

- RO swings to 5 V: into a 3.3 V ESP32 or Pi pin add a divider, or use a MAX3485 module.
- Keep the 120 ohm terminator only at the two ends of the bus.
- Own work: the 3D model is built from scratch from the dimensions above; no vendor art.
