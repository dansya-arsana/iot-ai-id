## Deploying

The deploy scripts are local and git-excluded on purpose. They name the server and key, and the repo is public. Never commit them.

- `deploy/deploy-web.sh`: static site only.
- `deploy/deploy-ops.sh`: API + ops containers, the idempotent nginx patches (each with a backup, `nginx -t` and automatic restore), then the static site and the public checks.
  - It refuses to run with uncommitted shipped paths, so commit first.
  - Data volumes are preserved. Never run `compose down -v`.

## Known limits

- Payouts are recorded, not executed: the transfer is manual, then it is marked paid with a reference.
- No email or SSO sign-in and no password reset by email. An owner resets the invite instead.
- Lockout and wrong credentials show the same message by design.
- An owner can reset another owner's invite. That is within the owner's authority, but it is worth knowing.
- Public site rule: no fake partners, schools or numbers. Show empty states honestly.
