# Outcome-led landing redesign

The landing presents useful hardware outcomes, practical learning, and an invitation to document tests in Indonesia. The supplier section describes a potential evaluation and distribution partnership. It does not claim an official distributor appointment, active tester population, stock, shipment availability, or verified robot performance.

## User-approved direction

The user selected the GetLayers Baseline style for supporting sections: white surfaces, blue accent, energetic but restrained motion. The hero composition follows the supplied humanoid product reference with original branding and artwork. The user explicitly asked to withhold official distributor claims.

## Public paths

The hardware library, learning material, public repository, desktop preview release, and downloadable partnership brief are available destinations. Public cloud project creation remains unavailable. The website must not imply anonymous cloud builds or a live community enrollment backend.

## Boundaries

Home and its dedicated presentation change. The public catalog now dynamically loads canonical bundled specifications on iot.ai.id so its CTA works without an owner API session. Local API failure uses a labeled read-only fallback. Internal canvas, API, runtime, admin authentication, and project behavior retain their existing implementations. Supplier business contact and official partner logos require separate factual input before publication.
