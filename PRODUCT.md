# iot.ai.id product context

This context records confirmed repository product facts for design work. It does not certify hardware execution or user research.

## Purpose and audience

iot.ai.id is a physical runtime and learning workspace for AI-assisted hardware experiments. Developers, agents, learners and future Hardware Fellows can describe a hardware goal, inspect a plan and contract, and work through wiring, code, flash, observation, verification and debugging.

The homepage is an interactive entrance to the workspace. Preserve the pinned public phrase “Give AI hands.” A hardware goal submitted through the existing prompt creates a project and opens its workspace.

## Product mechanism

The Hardware Contract records expected components, pins, voltage, protocol and behavior. Deterministic checks handle electrical and interface constraints. Runs produce structured evidence. Compilation and an agent's confidence do not establish physical success. Local execution is near hardware; cloud services coordinate work.

The reference build is an ESP32 room monitor with BME280 and an OLED. Its homepage visual is a reference, not telemetry. The disconnect-SDA homepage demo is an interactive illustration without hardware control.

## Truth boundaries

PhysicalBench presents methodology before proven rankings. Hardware specifications are not physical verification. Jakarta and Jabodetabek are planned proving grounds; Java is a future expansion corridor. The Indonesia Lab and Hardware Fellows program remain proposed. Do not invent lab activity, fellow profiles, counts, endorsements or verification results.

AI assistance processes the goal and machine evidence. Research reuse is separate and excluded by default. Keep the existing disclosure visible near the prompt.

## Current redesign boundary

The landing and its header/footer establish an adopted visual foundation. Existing project creation, navigation, prompt selectors and demo interactions remain functional. Fullscreen canvases and workbench layouts remain outside this change.
